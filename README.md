# Task 1 — Tabular Supervised Classification (Biomed-neyro)

Учебное задание: бинарная классификация табличных медицинских данных с помощью нейронной сети (MLP).

## Структура репозитория

    .
    ├── dataset/task1/
    │   ├── train.csv               # обучающая выборка (с таргетом)
    │   └── test_features.csv       # признаки для предсказания
    ├── outputs/
    │   └── task1_predictions.csv   # результат: patient_id, prediction
    └── your-sollution/
        ├── task1_solution.py       # основной скрипт
        └── task1_solution.ipynb    # ноутбук с тем же решением

## Данные

Медицинские табличные признаки пациентов (возраст, ИМТ, давление, липидный профиль, СКФ и др.).
Целевая переменная — `prediction` (0/1).

- **train.csv** — `patient_id`, 16 числовых/бинарных признаков, `prediction`, а также служебные колонки `Статус_глюкозы` и `Доклинический_риск` (исключаются как утечка).
- **test_features.csv** — те же признаки без таргета.
- **outputs/task1_predictions.csv** — `patient_id`, `prediction` в порядке исходного test-файла.

Классы несбалансированы (примерно 81.9% / 18.1%).

## Подход

Скрипт `your-sollution/task1_solution.py` следует 10 шагам из лекции:

1. Скачивание данных из репозитория
2. Загрузка CSV в pandas
3. Удаление выбросов по правилу IQR (только на train, `k=1.5`, бинарные флаги не трогаются)
4. Заполнение пропусков средним (`SimpleImputer`, fit только на train — без утечки)
5. Нормализация (`StandardScaler`, fit только на train)
6. Разделение на train / val / test (60 / 20 / 20, стратификация)
7. Обучение MLP: 1 скрытый слой, 32 нейрона, ReLU, 150 эпох
8. Генерация предсказаний для `test_features.csv`
9. Сохранение результата в `outputs/task1_predictions.csv`
10. Сдача кода и описания

### Учёт дисбаланса классов

Порог принятия решения подбирается по валидационной выборке так, чтобы максимизировать F1
(диапазон 0.05–0.95 с шагом 0.01). Порог по умолчанию 0.5 «схлопывает» все предсказания
в мажоритарный класс, поэтому подбор порога — корректный способ учесть дисбаланс
без изменения архитектуры сети.

### Защита от утечек

- Признаки `Статус_глюкозы` и `Доклинический_риск` исключены как сильно связанные с таргетом.
- Импутер и скейлер обучаются только на train-части.
- Выбросы удаляются только из train, `test_features.csv` не фильтруется.

## Запуск

Требуется Python 3.9+.

    pip install numpy pandas scikit-learn
    python your-sollution/task1_solution.py

Скрипт выводит шаги обработки, метрики на валидации и отложенном тесте, а также проверяет
контракт выходного файла (число строк, порядок `patient_id`, значения `prediction` ∈ {0, 1}).

## Метрики

Основные метрики — **ROC-AUC** и **F1** на отложенной выборке с подобранным порогом.
Точные значения выводятся в логе запуска скрипта.
